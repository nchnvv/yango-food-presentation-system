# Yango Food Presentation System

Библиотека для сборки презентаций Yango Food в Figma Design. Макеты рассчитаны на формат 16:9 (1920 × 1080).

Чтобы собрать новую презентацию, приложите бриф и отправьте в Codex:

> Собери новую редактируемую презентацию PowerPoint 16:9 по приложенному брифу. Используй правила структуры и оформления Yango Food из https://github.com/nchnvv/yango-food-presentation-system. Проверь PPTX после экспорта и приложи переданные архивы шрифтов.

## Сборка слайда

1. Добавьте нужный слайд из **Assets → Yango Food → Слайды**.
2. Замените текст, показатели и медиа в инстансе.
3. Добавьте нужные элементы из **Assets → Yango Food → Акценты** или **Данные**.
4. При изменении графика обновите подписи и вручную скорректируйте высоту столбцов либо положение точек и линий.

## Плашка

| Размер | Применение | Текстовый стиль | Отступы по горизонтали / вертикали |
| --- | --- | --- | --- |
| Метка | Период, этап, статус | Label | 20 / 10 px |
| Показатель | Изменение, отклонение, доля | Subheading | 28 / 16 px |
| Крупный | Главное число слайда | Heading | 36 / 20 px |

Ширина следует за текстом. Красный выделяет главное, Darkberry поддерживает второй уровень акцента, бежевый даёт контекст. В графиках серый используется для плана или базы сравнения.

## Композиционные приёмы

- **Полоса вывода** собирает итог или следующее действие в одну строку композиции.
- **Нумерованный тезис** ставит маркер, заголовок и пояснение рядом.
- **Вынос с показателем** связывает ключевое число с его интерпретацией.
- **Сравнение двух значений** выравнивает план и факт, выделяя разницу плашкой.
- **Контрастный блок** помогает сопоставить два сценария с одинаковой структурой.

## Токены и исходники

[Токены](presentation.tokens.json) фиксируют значения цветов, сетки, типографики и плашек для формата 1920 × 1080. Файл Figma служит источником компонентов. При изменении значений обновляйте Figma и JSON вместе.

Для редактирования текста нужны **Yango Group Headline** и **Yango Group Text**. Комплект для репозитория содержит документацию и значения токенов. PDF, шрифтовые файлы, логотипы и изображения Nom-Nom в комплект не входят.

## Сборка через Codex и Google Slides

[Инструкция и готовый запрос](GOOGLE-SLIDES.md) помогают команде собрать новую презентацию из своего брифа. [AGENTS.md](AGENTS.md) задаёт правила, по которым Codex выбирает композицию и проверяет результат.

## Веб-шрифты Yango

[fonts.css](fonts.css) подключает Headline Heavy и Text Regular / Medium с CDN Yango. [Тестовый слайд](web-font-demo.html) проверяет их загрузку в браузере. Для проверки скачайте оба файла в одну папку и откройте HTML. Готовый запрос для Codex приведён в [инструкции по сборке](GOOGLE-SLIDES.md).
